# ⏰ Smart Alarm Clock

A modern, professional, and fully responsive **Smart Alarm Clock** built using **HTML, CSS, and JavaScript**.

The project provides a clean digital clock interface with live time, current date, alarm scheduling, alarm sound, and responsive design for desktop and mobile devices.

## ⚙️ How It Works

### 1. Live Clock

JavaScript uses the `Date` object to retrieve the current time and updates the digital clock every second.

### 2. Alarm Setup

Users can select:

- Hour
- Minute
- AM/PM

and click **Set Alarm** to schedule an alarm.

### 3. Alarm Detection

The application continuously compares the current time with the selected alarm time.

When the times match, the alarm sound starts automatically.

### 4. Stop Alarm

The **Stop Alarm** button stops the sound and resets the active alarm.
